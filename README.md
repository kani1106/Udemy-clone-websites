# Udemy Clone (HTML & CSS)

A simple and responsive Udemy-style static website built using **pure HTML and CSS**.  
This project recreates the basic layout and design of an online learning platform, including a landing page, navigation bar, course sections, and UI components.

## 🌟 Features
- Fully responsive layout  
- Clean and modern UI  
- Course cards section  
- Header with navigation menu  
- Footer section  
- Built using only **HTML & CSS** 

## 📁 Project Structure
/project-folder
│── index.html
│── styles.css
│── /images

## 🎯 Purpose
This project was created to practice:
- Front-end layout design  
- CSS styling  
- Responsive web design  
- Building UI components using only HTML & CSS
